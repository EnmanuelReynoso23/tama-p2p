# Animo

A sprout that grows with you. You look after your pet, complete your daily habits and keep a streak
with your friends, connected directly between phones (P2P), with no server of my own. The small ESP32
device joins the same friends through a public MQTT broker ([`core/relay.js`](core/relay.js)).

Español: [README.es.md](README.es.md)

It runs in three places with the **same rules**:

- **Phone** (Android and iPhone): an installable web app (PWA) that works offline.
- **Raspberry Pi device**: the same app in kiosk mode (`?modo=maquina`) with 3 buttons.
  See [`machine/README.md`](machine/README.md).
- **ESP32-C3 egg**: JavaScript firmware with the Moddable SDK, compiled for the ESP32-C3 with
  ESP-IDF v6.1. See [`firmware/README.md`](firmware/README.md).

## How the pet works

The rules are in [`core/animo.js`](core/animo.js) and the drawings in
[`core/sprites.js`](core/sprites.js). They are plain JavaScript, used as they are by the app and the firmware.

| Stage | Starts at |
|-------|-----------|
| Egg   | 0         |
| Baby  | 2 minutes |
| Child | 12 hours  |
| Teen  | 2 days    |
| Adult | 5 days    |

- Needs go from 0 to 100: hunger, mood, energy, cleanliness and health. They drop over time; while
  asleep the pet recovers energy. It falls asleep on its own if it runs out of energy.
- An hour and a half after eating, it poops. Droppings or hunger lower its health; below 30 it gets
  sick and needs medicine.
- Adult form depends on how you cared for it (average care every half hour of play):
  **radiant** (grows a flower), **chill** (a wide hat-like leaf) or **scruffy** (messy leaves).
  A habit streak of 7 days or more moves it up one level.
- When you come back, the time you were away is simulated, up to one week.
- Petting raises its mood, capped at 10 per hour.

The drawings are generated by code (24x24 pixels): body, leaves per stage and a face that follows its mood.
The app icons come from those same drawings: `node scripts/make-icons.mjs`.

## Development

```bash
pnpm install
pnpm dev        # http://localhost:5173  (device mode: /?modo=maquina)
pnpm test       # tests for the core, the app, the network and the firmware screen
pnpm build      # checks types and builds dist/
```

Keys on a computer: `C` eat, `M` snack, `J` play, `B` bathe, `D` sleep.
Settings has an accelerated clock (x10, x60, x600) to watch the pet grow quickly.

## iPhone and Android

- Install it from the browser: on iPhone, Safari > Share > "Add to Home Screen"; on Android, the install
  prompt or the Chrome menu.
- Sound turns on with the first tap (iOS does not allow any sound before that).
- The game is saved on the phone. To move it to another device, use the transfer option in Settings
  (a QR code signed with ECDSA P-256).

## Structure

```
core/            shared rules and drawings (app + firmware) and their tests
src/
  store/         usePetStore (pet), useHabitStore (habits and streak), useP2PStore (friends)
  components/    screens: pet, habits, friends, settings, device mode
  network/       P2P (Yjs + WebRTC), MQTT bridge to the device, invitations, signing and game transfer
  sounds/        effects with Web Audio (no files)
  sprites/       turns the core drawings into canvas
firmware/        ESP32-C3 + ST7789 with the Moddable SDK
machine/         Raspberry Pi: kiosk + GPIO buttons
scripts/         icon generator
```
